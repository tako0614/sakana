# 統治制度

AIが調査、起草、審査と修正を進め、人間は法令で必要とされる投票・承認を行います。
ban・kickは承認後に管理者がDiscordで手動執行し、既存の案件カードの「執行完了」で記録します。Botにはban・kick・Administrator権限を付与しません。
機関と手続を固定のコード分岐へ閉じ込めず、憲法から委任された法律の定義として実行します。

- [憲法](constitution.md): 権利、権限委任、改憲の最低条件
- [統治組織手続法](founding-laws/organization.json): 初期機関、手続、投票・承認、処分・調査規則
- [実行の構造・法令定義・移行](autonomous-governance.md): 制度の変更方法と検証

`constitution.md` と初期法は新規導入時の文書です。導入済みサーバーの正本は統治DBにあり、
ファイルを変更するだけでは現行の憲法・法律は変わりません。
実行時のpolicyは現行憲法と成立法から生成し、別の設定ファイルを正本として持ちません。

各AI席が取得した記録、判断理由、証拠の再取得・照合、当事者への開示を記録します。
未取得の記録や開示していない不利な証拠をそのまま有罪判断の根拠にはできません。
法定の席数・必要票、答弁・上訴・承認期間と、技術的な再試行を区別して扱います。
